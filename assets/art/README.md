# Графика кинотеатра

Все изображения используются локально, сетевых запросов для графики нет.

| Файл | Назначение |
|---|---|
| `cinema-room-aligned.png` | Фон зала; основа для расположения объектов |
| `cinema-chair.png` | Кресло |
| `viewers.png`, `viewers-extra.png`, `viewers-diverse.png` | 12 персонажей: вид спереди, сзади и сидя |
| `viewers-back.png` | Задние позы восьми персонажей из первых двух атласов |
| `rug-1.png`, `rug-2.png` | Прямоугольные текстуры ковров, проецируемые на пол |

Это графика темы `classic`. Тема `cyberpunk` лежит в `assets/themes/cyberpunk/`
с теми же размерами и прозрачностью: `cinema-room.png` (фон зала, 1672×941),
`cinema-chair.png`, `rug-1.png`, `rug-2.png`. Пути и цвета тем заданы в `js/themes.js`.

Ходьба использует 12 кадров с небольшим махом и подъёмом ног; задние позы хранятся отдельно.
Варианты одежды и внешность выбираются по логину и сохраняются между сценами.

Постеры и текст вывески добавляются отдельно через `config.js`.
В `assets/posters/` лежат комплектные постеры игр; туда же можно добавлять свои.

При замене фона проверьте калибровку в `js/layout.js`, позиции постеров и
вывески в `js/decor.js`, а также маски и слои в `js/art.js`.
Для проверки используйте `tests/room_mesh.py` и браузерные тесты из README.
