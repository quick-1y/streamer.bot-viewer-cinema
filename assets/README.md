# Графика кинотеатра

Все изображения используются локально, сетевых запросов для графики нет.

```
assets/
├── themes/          оформление зала, по папке на тему
│   ├── classic/     дерево и бархат (по умолчанию)
│   └── cyberpunk/   неон
├── characters/      персонажи-зрители, общие для всех тем
└── posters/         комплектные постеры; сюда же можно класть свои
```

## Темы

В каждой папке темы лежат файлы с одинаковыми именами:

| Файл | Назначение |
|---|---|
| `cinema-room.png` | Фон зала, 1672×941, прозрачный вокруг зала; основа для расположения объектов |
| `cinema-chair.png` | Кресло |
| `rug-1.png`, `rug-2.png` | Прямоугольные текстуры ковров, проецируемые на пол |

Тема выбирается через `cinemaTheme` в `config.js`. Пути и цвета тем (ограждение,
рамки постеров, вывеска, лампы) заданы в `js/themes.js`. Новая тема — это новая
папка с теми же четырьмя файлами и запись в `js/themes.js`. Фон новой темы должен
повторять геометрию и прозрачность `classic/cinema-room.png` пиксель в пиксель.

## Персонажи

| Файл | Назначение |
|---|---|
| `viewers.png`, `viewers-extra.png`, `viewers-diverse.png` | 12 персонажей: вид спереди, сзади и сидя |
| `viewers-back.png` | Задние позы восьми персонажей из первых двух атласов |

Ходьба использует 12 кадров с небольшим махом и подъёмом ног; задние позы хранятся отдельно.
Варианты одежды и внешность выбираются по логину и сохраняются между сценами.

## Постеры и вывеска

Постеры и текст вывески настраиваются через `config.js`.

При замене фона проверьте калибровку в `js/layout.js`, позиции постеров и
вывески в `js/decor.js`, а также маски и слои в `js/art.js`.
Для проверки используйте `tests/room_mesh.py` и браузерные тесты из README.
